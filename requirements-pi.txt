# SENTRIX on a Raspberry Pi 5 (Raspberry Pi OS Trixie, 64-bit).
#
# Create the venv WITH system site packages so the apt camera and GPIO stack
# is visible (picamera2 / libcamera cannot be pip-installed; lgpio is the
# gpiozero pin factory on the Pi 5, RPi.GPIO does not work there; PortAudio
# is the microphone's C library):
#
#   sudo apt install -y python3-picamera2 python3-libcamera python3-lgpio libportaudio2
#   python3 -m venv --system-site-packages .venv
#   .venv/bin/pip install -r requirements-pi.txt
#
# ./run.sh does exactly this on a Pi, and sudo deploy/pi5/install_pi.sh does it
# plus the system setup (service user, systemd, watchdog, NetworkManager).
#
# Same packages as requirements.txt except: headless OpenCV < 5 (no Qt/X11 on
# the unit; 5.x is untested), no pytest, CPU torch. Install torch, torchvision
# and torchaudio from https://download.pytorch.org/whl/cpu FIRST (run.sh and
# install_pi.sh do): PyPI's aarch64 torch wheels pull several GB of NVIDIA
# CUDA libraries (nvidia-*-cu13, triton) that a Pi cannot use.
# ultralytics depends on opencv-python, and both builds provide cv2: run.sh and
# install_pi.sh uninstall opencv-python after this file and reinstall the
# headless build, so exactly one cv2 remains. Track T-HW owns this file; keep
# it in step with requirements.txt.
