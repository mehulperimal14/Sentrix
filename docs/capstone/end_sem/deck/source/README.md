# Deck source

The source of the final-evaluation deck (`../SENTRIX_CPG299_Deck.pdf`, `.pptx`): `deck.json` (slide
order, fonts), `deck.css` (the light editorial theme) and one HTML file per slide, speaker notes in each
slide's `<aside>`. The same files are published as the online deck; the PDF is printed from them with
headless Chrome, and the PPTX holds one picture per slide with the notes.
