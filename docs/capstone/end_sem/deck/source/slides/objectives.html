03 · Objectives (approved by the panel)

Five objectives, and where each one stands

O1

Multimodal AI pipeline

Detect weapons and fire, classify fights, recognise acoustic threats

Achieved · Pi latency open

O2

Threat Confidence Index

Fuse the modalities into one 0–1 score and five levels

Achieved · new method

O3

Tamper-evident evidence

AES-256-GCM bundles with SHA-256 digests

Achieved

O4

Physical edge unit

Camera and microphone input, board telemetry and GPIO status LEDs

Achieved · Pi 5, budget revised

O5

Console and alerting

Live dashboard, incident log, dispatch workflow

Achieved · 1 UI defect open

O2: the mid-semester XGBoost fusion was fitted to synthetic labels and ranked threats worse than its own inputs, so it was replaced by transparent evidence rules that give the same 0–1 TCI.

These are the objectives approved at the proposal; all five are achieved, two with an item open: the Pi’s latency target and one interface defect. The hardware moved from the ESP32 idea to a Raspberry Pi 5 with Camera Module 3, a USB microphone and three status LEDs, on the official 27-watt supply in a 3D-printed case, which raised the budget. The Threat Confidence Index came by a new method: the mid-semester fusion model was fitted to synthetic labels, so we replaced it with published rules that give the same 0–1 index and five levels.
