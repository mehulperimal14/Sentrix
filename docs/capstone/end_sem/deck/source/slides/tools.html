06 · Techniques and tools

Open-source tools, chosen by measurement

Perception

PyTorch, Ultralytics YOLO11n + ByteTrack, DINOv2 (timm), InsightFace, OSNet, PANNs CNN10, ONNX Runtime

Decision and data

Evidence rules, TCI, level policy, 4-second clip engine; SQLite (WAL), AES-256-GCM, HKDF, SHA-256 chains

Back end

Python, FastAPI, WebSockets, SQLAlchemy; Argon2id, TOTP, CSP and CSRF; outbound link and tunnel

Front end

React 19, TypeScript, Vite, Tailwind CSS 4, TanStack Query; two apps: device screen and Portal

Hardware

Raspberry Pi 5 (8 GB), Camera Module 3, USB microphone, official 27 W USB-C supply; Picamera2, gpiozero LEDs, systemd watchdog; OpenSCAD case, 3D-printed

Cloud and quality

Render (Docker, always on), Telegram Bot API, e-mail; pytest, Vitest, Playwright, replay and benchmarks

Choices were measured: slim CNNs lost to DINOv2 (0.229 vs 0.440 macro-F1), ONNX beat PyTorch on the Pi, and re-ID-trained OSNet-AIN beat colour histograms (AUROC 0.93 vs 0.73).

Everything is open source. Where we had a choice we measured it: the scene backbone, the runtime on the Pi and the body embedder were each picked by an experiment, not by preference. The Portal runs as a Docker service on Render and is always on, so nobody starts it by hand; the Pi starts SENTRIX as a service at boot.
